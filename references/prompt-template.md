# 五段式 Prompt 骨架与接续写法

## 目录
1. 五段式结构
2. 各段写法要点
3. 多段接续
4. 完整示例（门店套餐 15 秒）

## 1. 五段式结构

```text
## 1. 输入资产定位与 0 秒基准
## 2. 参考主体绑定与生成目标
## 3. 逐时间段动作、声音与脚本
## 4. 转场与尾态收束
## 5. 全片一致性与禁区
```

标题固定用这五个，不改名不合并。

## 2. 各段写法要点

### 第 1 段：输入资产定位与 0 秒基准
- 逐张点名图片，写清 URL、**采用**什么、**剥离**什么
- 采用 = 要继承的外观/身份/摆盘/光线关系
- 剥离 = 原图的构图、姿势、背景、服装、打光、覆盖层
- 结尾写 0 秒首帧状态：人物位置、动作、桌面摆布、光线
- 无人物参考时明确写"人物为概念形象，按第 2 段描述生成，不对应任何真实人物"

### 第 2 段：参考主体绑定与生成目标
- 一句话交代本段要完成的内容位置（不要重复第 1 段）
- 人物：年龄感、发型、妆容、服装、气质，逐项写
- 产品：形态/颜色/摆盘保持与哪张图一致
- 声音：语言、性别、语速、语气、是否对口型

### 第 3 段：逐时间段动作、声音与脚本
- 时间块按镜头切：`0–3 秒：景别 + 机位 + 动作 + 表情`
- 动作写到"哪只手、往哪个方向、接触什么、停在什么状态"
- 台词用花括号包住 `{原文}`，逐字不缩写
- 声音时间轴单独一段，逐句标时间、说话人、语气
- 环境声、动作声写具体（汤面接触声、掰瓣轻响、筷子夹取），不写"适当的音效"

### 第 4 段：转场与尾态收束
- 段内推进顺序一句话说完
- 明确"不做黑场、叠化、定格广告卡"
- 尾态要能被下一段接住：人在哪、手在做什么、产品在哪

### 第 5 段：全片一致性与禁区
- 身份/外观锚点复述一次（人物脸型发型服装、产品形态摆盘）
- 手部结构要求（五指完整、不多指、不变形）
- 禁止新增的元素（菜单、灯箱、二维码、品牌名、包装、假文字）
- 事实禁区直接用本片不可说清单
- 无字幕、无水印、无乱码文字

## 3. 多段接续

### physical 接续（同场景连续口播）
- 前段成功后抽真实尾帧（`-sseof -0.1` 附近），存 `05_视频片段/尾帧/SEG01_lastframe.jpg`，上传取 URL
- 后段首帧用该尾帧，Prompt 第 1 段写"为本段首帧与状态锚点"，并写"真实尾帧只提供可见状态，动作方向与速度按第 3 段展开"
- 后段图片顺序：尾帧 → 人物锚点 → 产品锚点
- 串行执行：尾帧实际到位后才提交，不并行

### montage 接续（换场/时间省略）
- 不传尾帧，各段独立生成
- 第 4 段写清因果、声音或视角的承接关系

## 4. 完整示例（门店套餐 15 秒，节选第 3 段）

```text
0–3 秒：中近景固定机位轻推。她双手扶锅沿，抬眼直视镜头，露出意外又满意的表情，开口抛钩子。
3–6 秒：同机位略低角度。她轻轻摇头，一只手掌心向上轻摊，桌边菜品从画面下缘入画。
6–11 秒：斜俯全桌缓移。她的手依次点过黑色长盘里的牛肉片、木架上的白豆腐、石碗鹌鹑蛋、油条豆卷与那一大把茼蒿，锅面热气升起。
11–15 秒：回到中近景。她夹起一片牛肉伸向红汤格，画面停在牛肉贴近汤面的瞬间。

声音时间轴：
0.3–2.8 秒，人物口播（女声，意外又满意）：{99 块一整桌？我本来以为就够点两盘肉。}
3.1–6.0 秒，人物口播（女声，吐槽共鸣）：{约火锅最烦点单，肉点少了不够吃，点多了又超预算。}
6.3–11.0 秒，人物口播（女声，逐样带过）：{你看这桌——牛肉片、豆腐、鹌鹑蛋、油条豆卷，青菜还一大把，红汤清汤一起开着。}
11.2–14.8 秒无台词，保留锅底沸腾声、筷子夹取声与汤面接触声。
```
