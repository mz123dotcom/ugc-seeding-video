# 各品类可说 / 不可说清单

## 通用规则

- 只说：看得见的外观、可复现的操作、主观体感、用户明确提供的价格与套餐内容
- 不说：任何需要核实的事实、功效承诺、绝对词、对比贬损、虚构身份与经历
- 绝对词清单：最、第一、全网最低、顶级、唯一、百分百、永久、零风险、闭眼入都值
- 不虚构：亲测次数、"我自己用了三年"、"老客户回购"、医生/专家角度、销量数字

## 通用可安全表达的句式

| 要做的事 | 安全写法 |
|---|---|
| 说好吃 | 咬下去、抿开、断面、挂汁、瓣肉状态这类可见描述 |
| 说好用 | 上手动作 + 反馈（按下去的手感、放桌上的样子） |
| 说划算 | 只复述用户给的价格与套餐包含什么，不推算折扣 |
| 说适合谁 | 具体场景与人数，不承诺人人适用 |

## 各品类禁区

### 食品生鲜（水果、零食、粮油）
不说：产地、品种名、糖度、无籽、农残、重量、价格、优惠、销量、认证、健康功效（补维C、助消化、降血糖等）、"当季头茬"等无法核实的时令宣称。
可替换：改说切开后的果肉状态、口感、分瓣多少、餐后解腻这类使用时刻。

### 餐饮门店 / 套餐
不说：门店名、地址、城市、营业时间、预约方式、原价、折扣、限时、库存、销量、评分、奖项、菜品克重、肉类品种、食材产地、健康功效。
可说：用户给的价格、桌上看到的菜品与锅底形态、涮煮几秒的变化、几人份够不够的体感、适合的聚会时刻。
画面禁区：不生成菜单文字、灯箱、二维码、品牌标识、店内海报。

### 饮品
不说：配料表具体数值、糖含量、卡路里、提神/助眠功效、冰镇时长、渠道价格。
可说：开盖、倒出、气泡、挂壁、喝下后的即时反应。

### 3C 数码
不说：品牌、型号、参数（无线、轴体、续航、刷新率、芯片）、性能对比结论、耐用年限、价格与优惠、库存。
可说：上手动作、按键/触控反馈、摆放场景、桌面观感、日常使用时刻。

### 家居日用
不说：材质成分、抗菌率、使用寿命、承重具体数值、认证。
可说：收纳前后对比、擦拭结果、归位后的动线变化。

### 美妆个护
不说：成分浓度、功效承诺（美白、祛痘、抗老）、医美效果、无刺激承诺、替代药品。
可说：取用、推开、上手上脸后的即时状态、日常上妆时刻。
注意：如涉及用户本人肤质困扰，只做产品使用场景描述，不给皮肤问题诊断。

## 真人肖像使用

- 用户上传真人照片时，先确认其有权使用该形象
- 采用范围默认只锁面部与发型，服装、背景、姿势剥离重设
- 成片不得暗示该真人为品牌代言人或有合作身份
- 不生成与政治人物、公众人物相似的真人面容

## 改写示例

| 原始说法（不可用） | 改写 |
|---|---|
| 这橙子糖度 16，甜到爆 | 你看这瓣肉，橙黄饱满，一瓣一瓣撑得圆圆的 |
| 全国最低价，只要 99 | 99 块一整桌（只复述用户给的价格） |
| 这家店是济南本地人排队王 | 两个人吃这一桌刚好，下班约一顿都合适 |
| 这键盘静音轴，办公不扰人 | 键帽按着顺手，摆上桌桌面一下就松快了 |
| 吃辣不上火，肠胃也舒服 | 红汤清汤一起开着，想吃哪边舀哪边 |
